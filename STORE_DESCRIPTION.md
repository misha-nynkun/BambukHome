# BambukHome 1.0.5 — описание для публикации

## Название

**BambukHome — локальное управление Bambu-принтером**

## Короткое описание

> Печать, AMS, камера, файлы и таймлапсы Bambu-принтера по домашнему Wi-Fi. Без облака, рекламы и подписок.

## Полное описание

**BambukHome** — независимый Android-клиент для локального управления 3D-принтерами Bambu Lab. Телефон и принтер работают в одной домашней Wi-Fi-сети, а управление идёт напрямую: без Raspberry Pi, промежуточного сервера и обязательного облака. Поддерживаются **P1S, P1P, X1, A1, H2D** и совместимые модели. Нужен Android 11 или новее.

Приложение создано для тех, кто хочет держать основные задачи под рукой на телефоне: посмотреть прогресс, поставить печать на паузу, поменять температуру, проверить AMS, открыть камеру, загрузить файл на SD-карту или посмотреть таймлапс. Для локального управления **не нужен аккаунт Bambu Lab** и не нужен постоянный доступ в интернет — достаточно, чтобы телефон и принтер были в одной сети.

### Главные плюсы

- **Локальное управление.** Основные команды идут напрямую на принтер по домашнему Wi-Fi. Нет обязательной привязки к облаку и нет Raspberry Pi.
- **Без аккаунта для локальных функций.** IP, код доступа и serial хранятся на телефоне. Аккаунт Bambu Lab нужен только для дополнительного раздела MakerWorld.
- **Полностью бесплатно.** Ни рекламы, ни подписок, ни платных уровней, ни встроенных покупок.
- **Несколько принтеров.** Профили с именами, моделями, IP, кодом доступа и serial. Переключение активного принтера — одним касанием.
- **Полноценный контроль печати.** Прогресс, слой, оставшееся время, ETA, стадия, HMS-ошибки, пауза, продолжение, остановка с подтверждением.
- **Температуры, вентиляторы, свет, движение.** Слайдеры и пресеты для сопла и стола, вентиляторы модели/дополнительный/камеры, перемещение X/Y/Z, парковка, экструзия и втягивание, произвольный G-code.
- **AMS и печать без AMS.** До четырёх слотов на юнит, несколько юнитов, влажность и температура, заправка/выгрузка, остатки, бренд, линия, температуры. Поддержка внешней катушки без AMS.
- **Файлы на SD по FTPS.** Список, папки, загрузка, скачивание и удаление файлов. Печать `.3mf`/`.gcode` с телефона с прогрессом.
- **Печать с параметрами.** Таймлапс, выравнивание стола, калибровка потока и вибраций, AMS-маппинг цветов.
- **3D-пластина из 3MF.** Интерактивный просмотр геометрии объектов на столе принтера: вращение одним пальцем, масштаб двумя, сетка стола.
- **Пропуск деталей.** Приложение читает 3MF с SD-карты, рисует реальные контуры деталей и позволяет отмечать их прямо на схеме стола — как в Bambu Handy. Понимает мультипластинчатые проекты Bambu Studio.
- **Камера.** Поток по TLS, полноэкранный режим, снимок в галерею, управление светом камеры и авто-свет при открытии.
- **Таймлапсы.** Встроенный плеер: AVI/MJPG читается собственным декодером, MP4/MKV — через Media3. Пауза, перемотка, время, кадры, fps. Есть демо-таймлапс без принтера.
- **Тихие уведомления.** Прогресс в шторке без звука, звук только у завершения и ошибок. Foreground-service держит мониторинг живым, пока идёт печать.
- **MakerWorld — опционально.** Поиск и карточки моделей работают без входа; после входа доступны «Мои модели», избранное, коллекции и скачивание 3MF. Пароль не сохраняется, токен входа шифруется.
- **Модели из разных источников.** MakerWorld, Thingiverse (API-токен), Printables (GraphQL), прямые ссылки. Для сайтов с Cloudflare/логином открывается точная страница в браузере.
- **Material You 3.** Динамические цвета Android 12+, светлая/тёмная/системная тема, **AMOLED-режим** с чистым чёрным фоном, настраиваемый акцент, масштаб интерфейса 85–130 %, шрифты Ndot 77 и свои `.ttf/.otf/.ttc`.
- **Настройка рабочего стола.** Порядок карточек и скрытие ненужных блоков; можно скрыть вкладки «Модели» и MakerWorld.
- **Демо-режим.** Можно посмотреть интерфейс, печать, AMS и настройки без принтера.
- **10 языков.** Русский, английский, немецкий, французский, испанский, итальянский, португальский, польский, турецкий, китайский.
- **Приватность.** Нет рекламы и аналитики. Локальные данные остаются на телефоне; пароль Bambu Lab не сохраняется, токен входа шифруется.

### Что нового в 1.0.5

- Настройка вкладок: «Модели» и MakerWorld можно скрыть, нижняя панель перестраивается сразу.
- 3D-пластина из 3MF: кнопка «3D» у выбранного файла и в недавних файлах.
- Ручная статистика: можно вписать общее число часов и завершённых печатей, дальше счёт продолжается автоматически.
- Кастомизируемый главный экран: порядок карточек и скрытие блоков.
- Material You 3-иконки: контурные в покое, залитые в выбранной вкладке.
- Более выразительные акцентные цвета и крупные контейнеры у кнопок управления.
- Обновлённый раздел «О приложении»: локальная работа, опциональный аккаунт, MakerWorld и хранение токена.

### Как это работает

1. На принтере включите **LAN Only Mode** и посмотрите IP, код доступа (8 символов) и серийный номер.
2. В BambukHome введите IP, код доступа, serial и модель.
3. Телефон и принтер должны быть в одной Wi-Fi-сети.
4. Приложение подключается к принтеру по **MQTT 8883 (TLS)**, файлы передаёт по **FTPS 990 (implicit TLS)**, камеру открывает по **TLS 6000**.
5. Для уведомлений во время печати используется foreground-service; для скачивания моделей — системная папка «Загрузки/BambukHome».

Сертификат принтера самоподписанный: приложение доверяет ему только в локальной сети, как Bambu Studio и эталонный бот. Для MakerWorld используется официальный Bambu Cloud; вход в браузере открывает официальный SSO Bambu Lab, cookie браузера приложению не передаются.

### Почему приложение сделано

Идея простая: телефон всегда под рукой, принтер стоит рядом, а для базовых задач не хочется поднимать ПК или Raspberry Pi, заводить аккаунт и зависеть от интернета. BambukHome закрывает локальный сценарий: подключился по IP, видишь статус, управляешь печатью, AMS, камерой и файлами. MakerWorld и облачный аккаунт — отдельный опциональный слой, а не обязательное условие.

Проект задуман как **бесплатный инструмент для сообщества**: без рекламы, подписок и платных функций. Все основные возможности доступны сразу; дополнительный аккаунт нужен только для тех, кто сам хочет пользоваться MakerWorld.

### Честные ограничения

- **Это не официальное приложение Bambu Lab.** Протокол неофициальный; после обновления прошивки отдельные функции могут измениться.
- Для локального управления нужен **LAN Only Mode** и одна Wi-Fi-сеть с принтером.
- Нет встроенного удалённого доступа через интернет; для этого нужен VPN или проброс портов, но это не рекомендуется.
- MakerWorld-скачивание требует аккаунта; исходный 3MF не содержит G-code — его нужно нарезать в Bambu Studio или OrcaSlicer.
- Приложение не гарантирует совместимость со всеми прошивками и моделями; перед важной печатью проверяйте параметры.
- Названия Bambu Lab и MakerWorld принадлежат их владельцам. Приложение не связано с Bambu Lab и использует названия только для обозначения совместимости.

## English short description

**BambukHome — local control for Bambu 3D printers.**

Control your Bambu Lab P1S/P1P/X1/A1/H2D over home Wi-Fi: print progress, pause/resume/stop, temperatures, fans, AMS, files over FTPS, camera, timelapses and quiet notifications. No cloud account is required for local control, and there are no ads or subscriptions. Optional MakerWorld search/download is available after signing in. Android 11+.
