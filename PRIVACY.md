# Политика конфиденциальности BambukHome

**Дата вступления в силу:** 22 ноября 2026 г.

BambukHome — независимый Android-клиент для локального управления 3D-принтерами Bambu Lab. Эта политика объясняет, какие данные использует приложение и как они хранятся.

## Коротко

- Приложение **не показывает рекламу** и **не содержит аналитики/трекеров**.
- Управление принтером работает **локально** по домашней Wi-Fi-сети.
- IP-адрес, код доступа, serial, профили принтеров, настройки и статистика хранятся **только на телефоне**.
- Аккаунт Bambu Lab **не обязателен** и нужен только для дополнительного раздела MakerWorld.
- Пароль Bambu Lab **не сохраняется**. Токен входа хранится в зашифрованном виде.
- Приложение не продаёт данные и не передаёт их разработчику.

## Какие данные хранятся на устройстве

- IP-адрес принтера, код доступа, серийный номер, модель и имя профиля.
- Настройки интерфейса: тема, AMOLED, акцент, масштаб, шрифт, порядок карточек.
- Настройки печати, папка загрузок, демо-режим.
- Локальная статистика: часы печати и число завершённых печатей.
- Токен входа Bambu Lab — только если пользователь сам включил MakerWorld; хранится зашифрованным.

Эти данные не отправляются разработчику. Удалить их можно очисткой данных приложения в настройках Android или удалением приложения.

## Сетевые подключения

Приложение подключается только к тем адресам, которые нужны для выбранной функции:

- **Локальный принтер:** MQTT 8883 (TLS), FTPS 990 (implicit TLS), камера 6000 (TLS).
- **MakerWorld / Bambu Cloud:** только если пользователь открыл раздел MakerWorld или вошёл в аккаунт.
- **Thingiverse / Printables / прямые ссылки:** только при открытии соответствующей модели.
- **Браузер:** для страниц, которые требуют Cloudflare/логин, приложение открывает системный браузер. Cookie браузера приложению не передаются.

Приложение не использует сторонние SDK рекламы, аналитики, краш-репортинга или трекинга.

## Аккаунт Bambu Lab / MakerWorld

Аккаунт полностью опционален. Если пользователь входит:

- email и пароль отправляются напрямую в официальный Bambu Cloud;
- пароль не сохраняется;
- токен входа хранится в зашифрованном виде;
- выход из аккаунта удаляет локальную сессию.

Политика Bambu Lab применяется к данным, которые обрабатывает сам Bambu Cloud.

## Разрешения

Приложение запрашивает только необходимые разрешения:

- `INTERNET` и состояние сети — для принтера и опционального MakerWorld.
- `ACCESS_NETWORK_STATE`, `ACCESS_WIFI_STATE` — чтобы определить доступность локальной сети.
- `POST_NOTIFICATIONS` — для тихого прогресса печати.
- `FOREGROUND_SERVICE` / `FOREGROUND_SERVICE_SPECIAL_USE` — чтобы мониторинг печати работал при свёрнутом приложении.

Приложение не запрашивает контакты, SMS, звонки, геолокацию, камеру телефона, микрофон, календарь и не имеет широкого доступа к файлам. Скачанные файлы сохраняются через MediaStore в «Загрузки/BambukHome».

## Передача данных третьим лицам

Разработчик не получает и не продаёт персональные данные. Данные могут обрабатываться третьими лицами только по инициативе пользователя:

- Bambu Cloud / MakerWorld — при входе и скачивании моделей;
- Thingiverse / Printables — при открытии моделей;
- браузер — при переходе на внешнюю страницу.

## Дети

Приложение не предназначено специально для детей и не собирает данные о детях.

## Изменения политики
